# 测试计划与用例

## 1. 测试目标

测试计划用于验证定转子 MES 系统是否满足需求规格、业务蓝图和系统设计要求，重点覆盖计划到完工、物料批次追溯、工艺防错、质量闭环、设备采集、接口联调、性能、安全和上线回归。

## 2. 测试范围

| 测试类型 | 范围 |
| --- | --- |
| 单元测试 | 状态机、编码规则、参数判定、检验判定、追溯关系写入。 |
| 集成测试 | ERP、PLM、WMS、QMS、EAM、SCADA/PLC、消息队列和文件服务。 |
| 系统测试 | 计划工单、工艺建模、生产执行、质量、设备、追溯、报表、权限。 |
| UAT | 业务端按真实班次、真实角色、真实产品路线执行端到端场景。 |
| 性能测试 | 工位扫码、报工过站、设备采集、追溯查询、看板刷新。 |
| 安全测试 | 登录、角色权限、数据权限、越权访问、审计日志。 |
| 灾备测试 | 服务重启、网络中断、边缘缓存、数据库备份恢复。 |

## 3. 测试环境

| 环境 | 用途 | 数据要求 |
| --- | --- | --- |
| DEV | 开发自测和接口模拟 | 小样本主数据，模拟设备数据。 |
| SIT | 系统集成测试 | 接近真实的产品、路线、设备、物料和接口数据。 |
| UAT | 用户验收 | 业务确认的典型产品与完整工单数据。 |
| PRE-PROD | 上线演练 | 生产配置快照、脱敏数据或上线盘点数据。 |
| PROD | 生产运行 | 正式主数据、正式接口和正式权限。 |

## 4. 准入与准出标准

### 4.1 测试准入

1. 需求、蓝图、设计和 UI 原型已评审通过并形成基线。
2. 被测版本完成开发自测和单元测试，阻断级缺陷为零。
3. 测试环境、接口模拟器、设备模拟器和基础主数据准备完成。
4. 测试用例已评审，关键用例已映射需求编号。

### 4.2 测试准出

1. Must 需求测试通过率 100%，Should 需求测试通过率不低于 95%。
2. 阻断级和严重级缺陷清零，中低级缺陷有业务批准的修复计划。
3. 性能、安全、接口和追溯专项测试达到验收阈值。
4. UAT 业务代表完成签字确认。

## 5. 缺陷等级

| 等级 | 定义 | 示例 |
| --- | --- | --- |
| Blocker | 阻断生产或核心流程无法继续。 | 工位无法扫码过站，工单无法发布。 |
| Critical | 严重影响业务且无可接受绕行方案。 | 参数超限未拦截，追溯数据丢失。 |
| Major | 影响部分业务，有临时绕行方案。 | 报表口径错误，异常通知延迟。 |
| Minor | 不影响主流程的小问题。 | 文案错误、布局轻微错位。 |
| Suggestion | 优化建议。 | 增加快捷筛选或导出字段。 |

## 7. 性能测试指标

| 场景 | 并发/数据量 | 验收指标 |
| --- | --- | --- |
| 工位扫码 | 100 个工位并发 | P95 响应 ≤ 1 秒，错误率 ≤ 0.1%。 |
| 报工过站 | 50 笔/秒峰值 | P95 响应 ≤ 2 秒，无重复报工。 |
| 设备采集 | 10 万点/分钟 | 数据丢失率 ≤ 0.01%，入库延迟 ≤ 5 秒。 |
| 单件追溯 | 1000 万条履历数据 | P95 查询 ≤ 10 秒。 |
| 看板刷新 | 20 块大屏 | 刷新周期 ≤ 30 秒，无明显卡顿。 |

## 8. UAT 场景包

1. 定子 A 产品从计划下达到终检入库全流程。
2. 转子 B 产品从计划下达到终检入库全流程。
3. 物料批次错投、工序跳站、人员资质过期和工装过期防错。
4. 首检不合格、返工复检、报废和让步接收。
5. 设备故障停机、恢复生产、报警追踪和 OEE 统计。
6. 客户投诉输入产品码后完成正向与反向追溯分析。
