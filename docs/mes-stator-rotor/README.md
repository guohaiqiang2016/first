## 系统建设目标

1. 打通定子、转子制造从计划、投料、生产执行、质量检验、设备采集到追溯分析的闭环。
2. 支撑新能源汽车电机核心部件的小批量多品种与批量稳定生产，提升计划达成率、一次合格率和设备利用率。
3. 建立以工单、批次、序列号、工艺路线、设备参数和质检结果为核心的全链路追溯体系。
4. 为 ERP、PLM、WMS、QMS、SCADA/PLC、条码/RFID、EAM 等系统提供标准集成能力。

## 适用范围

- 产品范围：定子铁芯、定子绕组、定子总成、转子铁芯、转子轴、转子总成及其关键子件。
- 车间范围：冲压/叠铆、绕线、嵌线、整形、绑线、浸漆/滴漆、固化、动平衡、压装、磁钢装配、充磁、终检、包装入库等。
- 管理范围：生产计划、工单派工、物料投退、过程采集、质量检验、设备状态、异常闭环、电子看板、报表分析、追溯管理。
