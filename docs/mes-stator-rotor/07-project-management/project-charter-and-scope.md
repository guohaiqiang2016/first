# 项目章程与范围说明

## 1. 项目概述

项目名称：汽车零部件制造定转子 MES 系统建设项目。

项目目标是在定子、转子制造车间建设统一的制造执行平台，实现生产计划下达、工单执行、工艺防错、质量检验、设备采集、物料追踪、异常闭环、生产看板和产品追溯的数字化管理。

## 3. 商业目标与成功标准

| 目标 | 衡量指标 | 目标值 |
| --- | --- | --- |
| 提升生产透明度 | 工单实时进度可视率 | ≥ 98% |
| 提升过程质量 | 关键工序参数采集完整率 | ≥ 99% |
| 强化追溯能力 | 单件追溯查询响应时间 | ≤ 10 秒 |
| 降低人工记录 | 纸质记录替代率 | ≥ 80% |
| 提升计划执行 | 日计划达成率 | ≥ 95% |
| 降低漏检误检 | 检验任务系统触发覆盖率 | ≥ 98% |

## 4. 项目范围

### 4.1 纳入范围

1. 生产计划接收、拆分、排产、工单下达与进度反馈。
2. 定子、转子工艺路线、工序、工装、设备、质量特性和采集点建模。
3. 条码/RFID 赋码、扫码报工、过站防错、物料批次绑定和关键参数采集。
4. 首检、巡检、完工检、返工复检、不合格品处理和质量追溯。
5. 设备状态采集、参数采集、点检保养提醒和设备异常联动。
6. 电子看板、产量报表、质量报表、设备 OEE、追溯报表。
7. 与 ERP、PLM、WMS、QMS、SCADA/PLC、EAM 的接口设计与实施。
8. 用户权限、审计日志、数据备份、上线培训和运维交接。

### 4.2 不纳入范围

1. ERP 财务核算、采购结算、销售订单管理。
2. PLM 工艺设计源头系统替代。
3. 设备 PLC 程序改造本体，但包含 MES 侧数据协议适配。
4. 自动化产线机械结构改造。
5. 高级 APS 优化算法深度实施；本期仅提供有限规则排产与人工调整。

## 7. 风险与假设

| 编号 | 风险 | 影响 | 应对策略 |
| --- | --- | --- | --- |
| R-01 | 设备接口协议不统一 | 采集延迟或范围缩水 | 建立设备清单和协议矩阵，优先打通瓶颈工序。 |
| R-02 | 主数据质量不足 | 排产、报工和追溯错误 | 上线前开展 BOM、工艺路线、物料、设备主数据清洗。 |
| R-03 | 现场网络不稳定 | 终端离线和数据丢失 | 关键工位部署边缘缓存和断点续传机制。 |
| R-04 | 用户操作习惯变化 | 推广阻力和数据不完整 | 设计简单交互、开展分角色培训、上线初期驻场支持。 |
| R-05 | 需求蔓延 | 进度延期 | 建立变更控制委员会，按 MoSCoW 优先级管理需求。 |

## 8. 验收原则

1. 以签字冻结的需求规格说明书、业务蓝图、设计说明书和 UAT 用例作为验收基线。
2. 阻断级缺陷必须全部关闭，严重级缺陷需有业务批准的临时方案。
3. 上线前必须完成数据初始化、权限分配、接口联调、培训签到和回退演练。
4. 上线后稳定运行期内，关键指标达到双方确认的上线验收阈值。
