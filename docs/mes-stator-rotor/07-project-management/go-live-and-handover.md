# 上线切换与运维交接

## 1. 文档目的

本文档用于定义定转子 MES 系统从 UAT 验收到生产上线的切换方案、上线检查、回退预案、培训安排、稳定期保障和运维交接要求，确保项目按照 PMP 收尾过程完成可控交付。

## 2. 上线策略

| 策略 | 说明 | 适用条件 |
| --- | --- | --- |
| 分产线试点 | 先选择一条定子线或转子线试点，稳定后推广。 | 现场复杂、设备接口多、用户变更较大。 |
| 分功能启用 | 先启用计划、报工、质量，再启用高级采集和报表。 | 主流程优先上线，部分接口待稳定。 |
| 双轨运行 | MES 与纸质记录短期并行，核对一致后取消纸质。 | 客户审核要求高或现场首次上线。 |
| 一次切换 | 所有产线同一窗口切换。 | 系统成熟、演练充分、风险较低。 |

推荐采用“分产线试点 + 双轨运行 1 至 2 个生产周期”的稳妥策略。

## 3. 上线前检查清单

| 类别 | 检查项 | 责任人 | 完成标准 |
| --- | --- | --- | --- |
| 需求 | Must 需求完成并通过 UAT | 项目经理/业务负责人 | UAT 签字。 |
| 缺陷 | 阻断和严重缺陷关闭 | 测试经理 | 缺陷清单确认。 |
| 数据 | 主数据、在制品、库存完成初始化 | 数据负责人 | 抽样核对通过。 |
| 接口 | ERP、WMS、QMS、设备接口联调通过 | IT/接口负责人 | 接口健康检查通过。 |
| 权限 | 用户、角色、数据权限配置完成 | 系统管理员 | 关键用户登录验证。 |
| 设备 | 工位终端、扫码枪、打印机、网关可用 | 设备/IT | 现场逐点检查。 |
| 培训 | 操作员、班组长、检验员、计划员完成培训 | 培训负责人 | 签到与考核通过。 |
| 运维 | 备份、监控、告警、应急联系人配置完成 | 运维负责人 | 演练记录完成。 |
| 回退 | 回退方案和数据处理方案评审完成 | 项目经理 | 回退演练通过。 |

## 4. 切换步骤

1. 冻结上线范围和版本，停止非紧急需求变更。
2. 备份生产数据库、配置文件、接口配置和前端资源。
3. 停止旧流程新增数据或进入双轨记录窗口。
4. 执行数据库脚本、应用部署、配置导入和主数据初始化。
5. 验证登录、权限、工单、扫码、检验、追溯、接口和看板。
6. 导入或确认上线时点在制品状态。
7. 发布上线通知，现场关键用户开始按 MES 执行业务。
8. 项目组驻场支持，按小时跟踪缺陷、异常和业务指标。
9. 完成上线首日总结，确认是否扩大范围或继续试点。

## 5. 回退预案

| 触发条件 | 回退动作 | 数据处理 |
| --- | --- | --- |
| 工位扫码大面积不可用超过 30 分钟 | 切回纸质报工和手工追踪 | 记录停机时点，恢复后补录。 |
| ERP/WMS 关键接口持续失败超过 2 小时 | 启用接口离线模板 | 保留离线单据，接口恢复后批量补传。 |
| 数据库故障且短时无法恢复 | 启用备份恢复或灾备环境 | 根据备份点和业务记录补齐差异。 |
| 追溯数据写入异常 | 暂停受影响工序扩线 | 核对日志和纸质记录，执行修复脚本。 |

回退决策由项目发起人、业务负责人、IT 负责人和项目经理共同确认，并记录原因、影响范围、恢复计划和责任人。

## 6. 培训计划

| 对象 | 培训内容 | 方式 | 考核 |
| --- | --- | --- | --- |
| 操作员 | 工位扫码、开工、报工、异常提报、离线处理 | 现场实操 | 独立完成一件产品过站。 |
| 班组长 | 派工、进度、异常处理、班组看板 | 课堂 + 现场 | 完成班组场景演练。 |
| 检验员 | 检验任务、结果录入、不合格创建 | 课堂 + 实操 | 完成首检和不合格用例。 |
| 计划员 | 计划接收、排产、工单发布、进度监控 | 课堂 | 完成排产发布演练。 |
| 工艺/设备 | 工艺路线、参数规则、采集点、设备状态 | 专题培训 | 完成配置变更演练。 |
| 管理层 | 看板、报表、追溯、指标口径 | 演示 | 能够独立查询指标。 |
| 运维人员 | 部署、监控、备份、日志、接口排障 | 技术培训 | 完成故障演练。 |

## 7. 稳定期保障

1. 上线后 2 至 4 周为稳定运行期，项目组提供现场或远程驻场支持。
2. 每日召开上线例会，跟踪缺陷、用户问题、数据一致性和关键 KPI。
3. 对 P1/P2 问题建立战情机制，明确响应时间、升级路径和临时绕行方案。
4. 每周输出上线运行报告，包括计划达成、报工及时率、参数采集率、接口成功率和缺陷关闭率。

## 8. 运维交接清单

| 交接物 | 内容 |
| --- | --- |
| 系统账号 | 管理员账号、服务账号、接口账号、密码交接方式。 |
| 部署文档 | 服务器清单、端口、服务、版本、配置、启动停止命令。 |
| 数据库文档 | 数据库连接、备份策略、恢复步骤、关键表说明。 |
| 接口文档 | 接口地址、认证、报文、错误码、重试策略、联系人。 |
| 设备采集文档 | 设备清单、采集点、协议、网关配置、故障排查。 |
| 用户手册 | 分角色操作手册、常见问题、异常处理指南。 |
| 测试与验收 | 测试报告、UAT 签字、遗留问题和解决计划。 |
| 运维手册 | 监控指标、告警规则、巡检清单、应急预案。 |

## 9. 项目收尾

1. 完成最终验收会议，确认范围、质量、进度和遗留事项。
2. 归档项目文档、源代码版本、配置版本、测试证据和验收签字文件。
3. 释放项目资源并移交给运维和业务持续改进团队。
4. 召开经验教训总结会，形成可复用的模板、风险库和最佳实践。
5. 项目经理提交项目收尾报告，项目发起人批准项目关闭。
