# 需求规格说明书

## 1. 文档目的

本文档用于定义汽车零部件定转子 MES 系统的业务需求、功能需求、非功能需求、数据需求、接口需求和验收追溯关系，作为项目范围控制、系统设计、开发测试和上线验收的基础。

## 2. 业务背景

定子、转子是新能源汽车驱动电机的关键部件，制造过程涉及多工序、多设备、多质量特性和严格追溯要求。传统纸质记录和离散设备数据难以满足高节拍生产、质量追溯、过程防错和客户审核要求，因此需要建设 MES 平台连接计划、现场、质量、设备和仓储数据。

## 3. 用户角色

| 角色 | 主要诉求 | 典型功能 |
| --- | --- | --- |
| 生产计划员 | 快速接收 ERP 计划并形成可执行工单。 | 计划导入、工单拆分、排产、进度监控。 |
| 班组长 | 掌握班组任务、异常和产量。 | 派工、工位开工、异常处理、看板。 |
| 操作员 | 按工艺指导完成扫码、装配、报工和自检。 | 工位作业台、SOP、扫码防错、报工。 |
| 质量检验员 | 按检验计划执行首检、巡检、终检和复检。 | 检验任务、数据录入、判定、不合格处理。 |
| 工艺工程师 | 维护工艺路线、参数和防错规则。 | 工艺建模、采集点、SOP、参数上下限。 |
| 设备工程师 | 监控设备状态和关键参数。 | 设备档案、采集配置、点检、报警。 |
| 仓库人员 | 保障投料、退料、完工入库准确。 | 备料、投料、线边库存、完工入库。 |
| 质量经理 | 分析质量趋势和追溯问题批次。 | 质量报表、SPC、追溯、8D 闭环。 |
| 系统管理员 | 维护用户、权限、字典和审计。 | 组织权限、菜单角色、日志、配置。 |

## 4. 功能需求

### 4.1 计划与工单管理

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-PLAN-001 | 系统应接收 ERP 生产计划、销售订单号、产品编码、数量、交期和优先级。 | Must | 接口或导入后形成待排计划，字段完整且可追溯来源。 |
| FR-PLAN-002 | 系统应支持按产品、工艺路线、批量规则将计划拆分为定子或转子工单。 | Must | 可生成工单号、批次号、计划数量、路线版本。 |
| FR-PLAN-003 | 系统应支持人工排产、优先级调整、产线/班次分配和锁定发布。 | Must | 已发布工单可在工位终端领取或自动派发。 |
| FR-PLAN-004 | 系统应实时显示工单开工、完工、暂停、报废、返工和入库状态。 | Must | 工单状态与现场报工同步，进度偏差可预警。 |

### 4.2 工艺路线与作业指导

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-TECH-001 | 支持维护定子、转子产品工艺路线、工序顺序、可选工序和返工路线。 | Must | 不同产品版本可绑定不同路线并保留历史版本。 |
| FR-TECH-002 | 支持为工序绑定设备、工装、模具、SOP、参数采集点和质量特性。 | Must | 工位作业时自动展示对应版本 SOP 和参数要求。 |
| FR-TECH-003 | 支持关键参数上下限、单位、采集频率和判定规则配置。 | Must | 超限时可阻止过站或触发异常流程。 |

### 4.3 生产执行与现场防错

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-EXEC-001 | 支持批次码、单件码、托盘码、工装码、物料批次码扫码绑定。 | Must | 绑定关系可用于正向和反向追溯。 |
| FR-EXEC-002 | 支持开工、暂停、恢复、完工、报废、返工、让步、入库等作业动作。 | Must | 每次动作记录人员、时间、工位、设备和原因。 |
| FR-EXEC-003 | 系统应校验工序顺序、物料匹配、设备状态、工装有效期和人员资质。 | Must | 不满足规则时提示原因并按权限放行。 |
| FR-EXEC-004 | 支持定子绕线、嵌线、整形、浸漆和转子压装、动平衡、充磁等关键工序参数采集。 | Must | 参数自动采集优先，手工录入需记录原因和审批。 |

### 4.4 质量管理

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-QUAL-001 | 支持首检、巡检、末检、完工检、抽检和复检任务自动生成。 | Must | 任务基于工单、工序、批量、时间或异常触发。 |
| FR-QUAL-002 | 支持检验项目、检验方法、规格上下限、AQL、判定和附件上传。 | Must | 检验结果自动判定合格、不合格或待复核。 |
| FR-QUAL-003 | 支持不合格品隔离、评审、返工、返修、报废、让步接收和 8D 闭环。 | Must | 状态流转完整，权限审批和原因代码可追溯。 |
| FR-QUAL-004 | 支持质量趋势、缺陷 Pareto、直通率、一次合格率和 SPC 分析。 | Should | 报表可按产品、批次、产线、工序、设备维度筛选。 |

### 4.5 设备与数据采集

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-EQP-001 | 支持设备台账、产线、工位、状态字典、采集协议和采集点配置。 | Must | 设备状态可展示运行、待机、故障、保养、离线。 |
| FR-EQP-002 | 支持通过 OPC UA、Modbus TCP、PLC 网关、HTTP/MQTT 等方式采集设备数据。 | Must | 采集数据带时间戳、设备号、工单号和产品标识。 |
| FR-EQP-003 | 支持设备报警、停机原因、点检、保养提醒和异常工单关联。 | Should | 报警可推送给班组长和设备工程师。 |

### 4.6 追溯与报表

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-TRACE-001 | 支持按单件码、批次号、工单号、客户批次、物料批次查询追溯链。 | Must | 可查询人员、设备、工艺、物料、参数、检验和异常。 |
| FR-TRACE-002 | 支持正向追溯物料批次影响的产品范围。 | Must | 输入物料批次后输出关联工单、产品和库存位置。 |
| FR-TRACE-003 | 支持生产、质量、设备、计划、库存和异常看板。 | Should | 看板数据刷新周期可配置，支持大屏展示。 |

### 4.7 系统管理

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-SYS-001 | 支持组织、用户、角色、菜单、数据权限和审批权限配置。 | Must | 同一用户可按工厂、车间、产线限定数据范围。 |
| FR-SYS-002 | 支持操作日志、接口日志、设备采集日志和异常审计。 | Must | 关键变更可追溯变更前后值。 |
| FR-SYS-003 | 支持字典、编码规则、消息模板、班次日历和系统参数维护。 | Must | 编码规则可配置前缀、日期、流水号和校验位。 |

## 5. 非功能需求

| 类别 | 需求 |
| --- | --- |
| 性能 | 工位扫码响应时间 P95 ≤ 1 秒；追溯查询 P95 ≤ 10 秒；看板刷新周期 ≤ 30 秒。 |
| 可用性 | 生产时间系统可用性 ≥ 99.5%；关键工位支持边缘缓存和断点续传。 |
| 安全 | 支持 RBAC、密码策略、单点登录可选、传输加密、敏感操作二次确认。 |
| 可维护性 | 模块化服务、统一日志、统一监控、接口可追踪、配置化工艺规则。 |
| 可扩展性 | 支持新增产线、设备协议、产品路线和工厂组织扩展。 |
| 合规 | 满足 IATF 16949、客户审核、过程质量记录保存和电子记录审计要求。 |
| 易用性 | 工位页面应适配触摸屏，关键操作不超过三步，异常提示明确可执行。 |

## 6. 数据需求

| 数据域 | 主数据/业务数据 | 来源 | 维护责任 |
| --- | --- | --- | --- |
| 产品 | 产品、BOM、替代料、客户料号 | ERP/PLM | 工艺/计划 |
| 工艺 | 路线、工序、SOP、参数、检验项目 | PLM/MES | 工艺工程师 |
| 资源 | 工厂、车间、产线、工位、设备、工装、模具 | MES/EAM | 设备工程师 |
| 计划 | 生产计划、工单、排产、班次 | ERP/MES | 计划员 |
| 执行 | 报工、过站、绑定、返工、报废 | MES | 车间人员 |
| 质量 | 检验结果、不合格、缺陷、8D | MES/QMS | 质量人员 |
| 采集 | 设备状态、工艺参数、报警 | SCADA/PLC | 设备/IT |
| 追溯 | 单件履历、批次履历、谱系关系 | MES | 系统自动生成 |

## 7. 接口需求

| 接口 | 方向 | 主要数据 | 频率 |
| --- | --- | --- | --- |
| ERP → MES | 下行 | 生产计划、物料、BOM、库存、客户订单 | 定时/实时 |
| MES → ERP | 上行 | 完工入库、报废、工时、物料消耗 | 实时/批量 |
| PLM → MES | 下行 | 工艺路线、SOP、图纸、质量特性 | 版本发布时 |
| WMS ↔ MES | 双向 | 备料、投料、退料、线边库存、入库 | 实时 |
| QMS ↔ MES | 双向 | 检验标准、不合格、8D、质量放行 | 实时/定时 |
| SCADA/PLC → MES | 上行 | 设备状态、参数、报警、节拍 | 秒级/事件 |
| EAM ↔ MES | 双向 | 设备台账、点检、保养、维修工单 | 定时/事件 |

## 8. 需求优先级规则

采用 MoSCoW 方法管理需求优先级：Must 为本期上线必须具备能力，Should 为上线价值高但可在资源不足时降级，Could 为增强体验能力，Won't 为本期不实施但保留后续规划。

| 生产透明 | FR-PLAN-001 至 FR-PLAN-004、FR-EXEC-002、FR-TRACE-003 | 工单全流程、看板刷新、状态同步用例。 |
| 过程防错 | FR-TECH-002、FR-TECH-003、FR-EXEC-001 至 FR-EXEC-004 | 扫码防错、参数超限、工序顺序校验用例。 |
| 质量闭环 | FR-QUAL-001 至 FR-QUAL-004 | 首检、巡检、不合格评审、返工复检用例。 |
| 设备采集 | FR-EQP-001 至 FR-EQP-003 | 采集协议、状态转换、报警联动用例。 |
| 全链路追溯 | FR-TRACE-001、FR-TRACE-002、数据需求、接口需求 | 正反向追溯、批次影响分析用例。 |
